# 🎓 Diploma Admission System (Admin Module)

## 📌 Overview
This project is a web-based College Admission System developed as a Diploma Final Year Project.

It is designed specifically for administrative use to manage the entire admission process digitally, including student applications, merit list generation, and seat allocation.

---

## 🚀 Features
- Admin Dashboard  
- Student Application Management  
- Merit List Generation  
- Seat Allocation based on Category & Marks  
- Course/Branch Management  
- Data Handling and Record Management  

---

## 🛠️ Technologies Used
- PHP  
- MySQL  
- HTML  
- CSS  
- JavaScript  
- XAMPP  

---

## 🧠 Key Functionality
- Automated merit list generation based on student marks  
- Seat allocation logic considering reservation categories (SC/ST/OBC/General)  
- Centralized admin control for managing admissions  
- Efficient handling of student records  

---

## ▶️ How to Run
1. Install XAMPP  
2. Copy project folder to `htdocs`  
3. Start Apache & MySQL  
4. Import the database (`.sql` file) into phpMyAdmin  
5. Open browser and run:  
   http://localhost/Diploma-Admission-System
